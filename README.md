# CaseHunter AI

AI-assisted Arabic news and story production studio for YouTube Shorts and long-form videos.

## MVP
- Discover story candidates from configured sources
- Research and fact-check with multiple sources
- Generate original scripts
- Produce Short and Long video variants
- Render media with FFmpeg
- Review before publishing
- Publish/schedule through official YouTube APIs
- Track analytics

> The system is designed for original, source-backed content. It does not download and re-upload other creators' videos.
